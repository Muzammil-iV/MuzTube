# 🎬 MuzTube - Video Downloader

**Download videos from YouTube, Instagram, TikTok, Facebook, Twitter/X & more.**

[![Live](https://img.shields.io/badge/Live-muztube.up.railway.app-blue)](https://muztube.up.railway.app)
[![License](https://img.shields.io/badge/License-MIT-yellow)](LICENSE)

---

## ✨ Features

- 🎬 Video & 🎧 Audio download
- ⚙️ Quality selector (2160p to 360p)
- 📦 Format options (MP4, MKV, MP3, M4A)
- 📥 Real-time progress bar
- 📋 Copy yt-dlp command
- 🎨 Clean minimal UI
- 📱 Mobile responsive
- 🔒 No ads, no tracking

## 📦 Local Setup

```bash
git clone https://github.com/themuzammilnawaz/MuzTube.git
cd MuzTube
pip install -r requirements.txt
python app.py
```
